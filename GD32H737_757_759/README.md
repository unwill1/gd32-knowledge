# GD32H737 / H757 / H759 外设知识库

本知识库供 AI Agent 通过文件系统检索 GD32H737/H757/H759 外设信息。
内容来源：用户手册（User Manual）。

## Agent 使用约定（重要）

1. **先读 `_catalog.md`** 确认目标外设及其目录路径，不要盲目遍历。
   - `_catalog.md` 包含别名列，可用英文缩写（如 SPI、DMA）快速定位。
2. 进入外设目录后，**按文件名后缀选择**：
   - `_特性及功能.md` → 问功能原理、工作模式、配置流程时读这个
   - `_寄存器.md` → 问寄存器定义、bit 含义、复位值、读写属性时读这个
3. 查具体寄存器/bit → 读 `_寄存器.md`；查功能/原理/配置流程 → 读 `_特性及功能.md`。
4. **特殊拆分外设**（已按子模块细分）：
   - TIMER（24）→ 11 个子文件，先读 `24_TIMER_概览与分类.md`
   - WDGT（22）→ 4 个子文件（独立/窗口 × 特性/寄存器）
5. 跨外设的应用主题 → 见顶层 `app-notes/`（当前待完善）。

## 目录结构

```
peripherals/
  {章节号}_{中文名}（{英文缩写}）/
    {章节号}_{中文名}（{英文缩写}）_特性及功能.md
    {章节号}_{中文名}（{英文缩写}）_寄存器.md
    images/                ── 该外设的图片资源
app-notes/        ── 跨外设应用笔记（待完善）
_catalog.md       ── 全局外设索引（Agent 入口）
```

## 与 H77x/H78x 的关系

GD32H737/757/759 与 H77x/H78x 属同系列，外设大部分相同但章节编号不同。
本知识库已独立录入，使用本目录下的资料即可，无需跳转到 H77x_H78x。
