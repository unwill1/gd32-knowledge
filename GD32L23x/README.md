# GD32L23x 外设知识库

本知识库供 AI Agent 通过文件系统检索 GD32L23x 外设信息。
内容来源：GD32L23x 用户手册 Rev2.6（2026 年 1 月），覆盖 GD32L233xx、GD32L235xx 系列，内核为 Arm Cortex-M23。

## Agent 使用约定（重要）

1. **先读 `_catalog.md`**，按别名或中文名确认目标外设目录。
2. 进入目录后按文件名选择：
   - `_特性及功能.md` → 功能原理、工作模式、配置流程
   - `_寄存器.md` → 寄存器定义、bit 含义、复位值、读写属性
3. WDGT（16）按独立看门狗和窗口看门狗拆分；先读 `16_WDGT_概览与分类.md`。
4. TIMER（18）按高级、通用 L0、通用 L1、通用 L3、基本定时器分别拆分特性与寄存器；先读 `18_TIMER_概览与分类.md`。
5. LPTIMER（19）是独立的低功耗定时器外设，不要与 TIMER（18）的各定时器类型混用。
6. 手册中部分功能仅适用于 GD32L233xx 或 GD32L235xx；查询时应保留原文的型号适用条件。

## 与其他系列的关系

GD32L23x 与其他 GD32 系列的同名外设可能具有不同的寄存器布局、bit 定义和章节编号。
查询时仅使用本目录资料；除非明确要求比较或参考，否则不要跨系列套用。
