# GD32 MCU 知识库

面向 GD32 MCU 外设资料检索与技术支持的本地知识库。内容按芯片型号分组，包含外设索引、功能说明、寄存器章节、应用笔记和必要的原始资料。

## 当前型号分组

- `GD32C2x1`：C231
- `GD32E51x`：E513 / E517 / E518 / EPRTxxA
- `GD32F30x`：F303 / F305 / F307
- `GD32F4xx`：F405 / F407 / F450 / F470
- `GD32F50x`：F502 / F503 / F505
- `GD32F527`：F527
- `GD32G553`：G553
- `GD32H737_757_759`：H737 / H757 / H759
- `GD32L23x`：L233 / L235

每个分组优先从 `_catalog.md` 定位目标外设，再进入 `peripherals/` 读取功能或寄存器章节。

## 仓库边界

- `tmp/`、`work/`、`output/` 为本地临时或审阅产物，不纳入版本控制。
- `GD32H77x_H78x/` 及其历史归档含明确标注为 NDA/Confidential 的资料，在确认第三方云存储授权前不纳入远程仓库。
- 本仓库未声明开源许可证。原始手册、应用笔记及其内容的权利归对应权利人所有；对外公开前应逐项确认授权和再分发条件。

## 使用原则

1. 先确认准确芯片型号，再进入对应分组。
2. 寄存器、bit、复位值、读写属性和电气参数以目标型号正式资料为准。
3. 不跨系列直接套用同名外设定义；资料冲突时优先采用最新勘误、数据手册和用户手册。
