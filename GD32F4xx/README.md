# GD32F4xx 外设知识库

本知识库供 AI Agent 通过文件系统检索 GD32F4xx 外设信息。
内容来源：用户手册（User Manual）。覆盖 GD32F405 / F407 / F450 系列。

## Agent 使用约定（重要）

1. **先读 `_catalog.md`** 确认目标外设及其目录路径，不要盲目遍历。
   - `_catalog.md` 包含别名列，可用英文缩写（如 SPI、DMA）快速定位。
2. 进入外设目录后，**按文件名后缀选择**：
   - `_特性及功能.md` → 问功能原理、工作模式、配置流程时读这个
   - `_寄存器.md` → 问寄存器定义、bit 含义、复位值、读写属性时读这个
3. 查具体寄存器/bit → 读 `_寄存器.md`；查功能/原理/配置流程 → 读 `_特性及功能.md`。
4. **特殊拆分外设**（已按子模块细分）：
   - TIMER（18）→ 11 个子文件，先读 `18_TIMER_概览与分类.md`
   - WDGT（16）→ 5 个子文件（概览 + 独立看门狗/窗口看门狗 各特性+寄存器）

## 目录结构

```
peripherals/
  {章节号}_{中文名}（{英文缩写}）/
    {前缀}_特性及功能.md
    {前缀}_寄存器.md
    images/                ── 该外设的图片资源
_catalog.md       ── 全局外设索引（Agent 入口）
```

## 与其他系列的关系

GD32F4xx 属 Cortex-M4 系列，外设与 GD32F30x 有部分重叠但章节编号不同。
使用本目录下的资料即可，无需跳转到其他系列。
