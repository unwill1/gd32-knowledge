# GD32E51x 外设知识库

本知识库供 AI Agent 通过文件系统检索 GD32E51x 外设信息。
内容来源：GD32E51x 用户手册 Rev1.6（2026 年 1 月），覆盖 GD32E513xx、GD32E517xx、GD32E518xx、GD32EPRTxxA 系列，内核为 Arm Cortex-M33。

## Agent 使用约定（重要）

1. **先读 `_catalog.md`**，按别名或中文名确认目标外设目录。
2. 进入目录后按文件名选择：
   - `_特性及功能.md` → 功能原理、工作模式、配置流程
   - `_寄存器.md` → 寄存器定义、bit 含义、复位值、读写属性
3. 系统及存储器架构（1）原章没有独立寄存器节，因此只有 `_特性及功能.md`。
4. WDGT（16）按独立看门狗和窗口看门狗拆分；先读 `16_WDGT_概览与分类.md`。
5. TIMER（18）按高级、通用 L0、L1、L2、L3、L4、基本定时器分别拆分特性与寄存器；先读 `18_TIMER_概览与分类.md`。
6. USART（20）和 I2C（21）各自包含两套功能及寄存器章节，已分别归入统一的特性文件和寄存器文件；查询时继续按文件内 20.1/20.2、21.1/21.2 标题定位实例。

## 与其他系列的关系

GD32E51x 与其他 GD32 系列的同名外设可能具有不同的寄存器布局、bit 定义和章节编号。
查询时仅使用本目录资料；除非明确要求比较或参考，否则不要跨系列套用。
