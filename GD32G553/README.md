# GD32G553 外设知识库

本知识库供 AI Agent 通过文件系统检索 GD32G553 外设信息。
内容来源：用户手册（User Manual）。覆盖 GD32G553 系列。

## Agent 使用约定（重要）

1. **先读 `_catalog.md`** 确认目标外设及其目录路径，不要盲目遍历。
   - `_catalog.md` 包含别名列，可用英文缩写（如 SPI、DMA）快速定位。
2. 进入外设目录后，**按文件名后缀选择**：
   - `_特性及功能.md` → 功能原理、工作模式、配置流程
   - `_寄存器.md` → 寄存器定义、bit 含义、复位值、读写属性
3. `_catalog.md` 中标有 `⚑` 的条目目前为单文件，直接读取索引指定的文件。
4. TIMER（23）按高级、通用 L0、通用 L3、通用 L4、基本定时器分别拆分特性与寄存器文件；查询前先读 `23_TIMER_概览与分类.md` 定位类型。
5. IFRP（26）原文明示该模块没有独立寄存器，由 TIMER15、TIMER16 和 SYSCFG/GPIO 配置，因此只有 `_特性及功能.md`。

## 与其他系列的关系

GD32G553 基于 Arm Cortex-M33。即使外设名称与其他 GD32 系列相同，寄存器布局、bit 定义和章节编号也可能不同。
查询时仅使用本目录资料；除非明确要求比较或参考，否则不要跨系列套用。
