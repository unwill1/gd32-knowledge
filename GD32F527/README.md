# GD32F527 外设知识库

本知识库供 AI Agent 通过文件系统检索 GD32F527 外设信息。
内容来源：GD32F527xx 用户手册 Rev1.4（2026 年 1 月），覆盖 GD32F527xx 系列，内核为 Arm Cortex-M33。

## Agent 使用约定（重要）

1. **先读 `_catalog.md`** 确认目标外设及目录路径，不要盲目遍历。
2. 进入外设目录后，按问题类型选择文件：
   - `_特性及功能.md`：功能原理、工作模式、配置流程。
   - `_寄存器.md`：寄存器定义、bit 含义、复位值、读写属性。
   - `_概览与分类.md`：按实例或子类型定位后续文件。
3. `_catalog.md` 中标有 `⚑` 的条目为单文件，直接读取“文件”列指定文件。
4. 特殊拆分外设：
   - WDGT（20）：独立看门狗、窗口看门狗，先读 `20_WDGT_概览与分类.md`。
   - TIMER（22）：高级、通用 L0、通用 L1、通用 L2、基本五类，先读 `22_TIMER_概览与分类.md`。
   - I2C（24）：I2C0/1/2 与 I2C3/4/5 使用不同寄存器布局，先读 `24_I2C_概览与分类.md`。

## 与其他系列的关系

GD32F527 与其他 GD32 系列的同名外设可能具有不同的寄存器布局、bit 定义和章节编号。
查询时仅使用本目录资料；除非明确要求比较或参考，否则不要跨系列套用。
