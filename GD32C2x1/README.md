# GD32C2x1 外设知识库

本知识库供 AI Agent 通过文件系统检索 GD32C2x1 外设信息。
内容来源：GD32C2x1 用户手册 Rev1.2（2026 年 6 月），覆盖 GD32C231xx 系列，内核为 Arm Cortex-M23。

## Agent 使用约定（重要）

1. **先读 `_catalog.md`**，按别名或中文名确认目标外设目录。
2. 进入目录后按文件名选择：
   - `_特性及功能.md` → 功能原理、工作模式、配置流程
   - `_寄存器.md` → 寄存器定义、bit 含义、复位值、读写属性
3. WDGT（12）按独立看门狗和窗口看门狗拆分；先读 `12_WDGT_概览与分类.md`。
4. TIMER（14）按高级、通用 L0、通用 L2、通用 L4 分别拆分特性与寄存器；先读 `14_TIMER_概览与分类.md`。

## 与其他系列的关系

GD32C2x1 与其他 GD32 系列的同名外设可能具有不同的寄存器布局、bit 定义和章节编号。
查询时仅使用本目录资料；除非明确要求比较或参考，否则不要跨系列套用。
